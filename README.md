A high-converting, interactive Return on Investment (ROI) calculation pipeline designed to quantify the financial difference between manual administration, subscription-based middleware rentals, and custom bespoke code scripts.

---

## 🎯 The Product Concept: Code as an Asset, Not a Rental

Modern SaaS platforms hook businesses into recurring subscription cycles. Software like Zapier, Make, or custom automation wrappers become permanent operational drains, where monthly subscription costs scale brutally alongside business growth.

The core product thesis of this engine addresses this exact problem: **Custom automation should be owned as an appreciating business asset, not rented as an ongoing dependency.** This interactive pipeline guides prospective clients through a rapid, self-directed assessment. It pairs manual labor operational drains and subscription overhead calculations with a custom complexity matrix. This allows the system to visually prove how a one-off custom script script fully amortises its initial build investment within a matter of months.

---

## ⚙️ Architectural Intent & Strategy

Lead acquisition tools often suffer from high bounce rates when they present static, uninspired form questionnaires. This repository establishes a highly engaging, gamified conversion funnel that builds user authority before introducing a Call to Action (CTA).

This static prototype achieves three primary architectural milestones:
1. **Interactive Multi-Stage State Progression:** Isolates discrete configuration variables across a fluid, state-managed wizard wrapper. The interface updates structural progress metrics dynamically while preserving element values across steps.
2. **Asynchronous Processing Simulation:** Uses event-driven window delays to decouple form input collection from final mathematical output. This mocks real-time algorithmic feasibility calculations through a stylised terminal logging box, enhancing trust in the results.
3. **Reactive Vector Data Visualisation:** Translates user-configured range states and input parameters directly into relative multi-variable comparisons, rendering a high-performance vector bar chart directly onto the browser layout space.

## 💎 Core Features & Engineering Highlights

### 📋 Complexity-Weighted Investment Matrix
* Implements a decoupled calculation array where distinct workflow bottlenecks (Data Entry, Financial Reconciliations, Client Onboarding, E-Commerce Operations) carry individual underlying complexity weights.
* Combines selected project parameters with a standard base configuration cost to dynamically scale the estimated target build cost in the background.

### 📊 Multi-Variable Amortisation Engine
* Synthesises ongoing monthly labor costs based on custom weekly range values multiplied by local team billable rates.
* Compiles comparative two-year cost projections by running concurrent tracks:
  * **Manual Overhead:** Tracks pure, long-term labor spending.
  * **Subscription Middleware:** Models the compounded fee structures of continuous tool renting patterns.
  * **Custom Bespoke Code:** Isolates the single, upfront build cost against a baseline long-term support parameter.
* Programmatically calculates the exact break-even timeline, highlighting the milestone directly to the user.

### 💻 Event-Driven Terminal Logging
* Simulates terminal processes through a custom encapsulated container using monospace font assets (`Fira Code`).
* Uses structured string array indexing alongside automated insertion loops to sequentially prepend code-style logging status messages, terminating with localised visual style changes to signal a successful completion.

## 🎨 Design Philosophy: Cognitive Flow
* **Lato and Poppins Scaffolding:** Pairs geometric heading typography tokens for corporate authority with an exceptionally clean, readable sans-serif text canvas for effortless number processing.
* **Warm Minimalist Color Mapping:** Rejects traditional cold corporate tech aesthetics, adopting a soft cream void canvas background (`#FDFBF7`) accented by a deliberate amber brand focus (`#F09B3E`) and high-impact magenta hero elements (`#C22B5D`).
* **Frictionless Form Elements:** Replaces rigid numeric text input boxes where possible with responsive slider elements, allowing users to rapidly configure variables without encountering typing friction.
